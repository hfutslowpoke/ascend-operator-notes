# 可迁移的算子设计手册

## 从语义压缩开始

先写完整依赖：真实 X/W/scale/group_list → true-K 整数累加 → FP32 非线性 → 最终输出。列出可退化的参数维、有限值域、重复子表达式、跨行共享量。K=1 不应机械看成“很瘦的 GEMM”；N=1 不应默认支付通用 Cube 输出通路成本。

算法选择以一般参数族和硬件容量为依据。不能用完整 case 元组、替换后的唯一识别符或数据生成规律伪装逐 case 跳算。实际数据相关分组、压缩、表生成与数值计算留在 Device；每次调用都由当前输入生成结果。

## 成本表与多级下界

对每个算法族计算：有效整数 MAC、padding 后实际 MAC、FP32 非线性元素数、每层读写、布局转换、元数据成本、所有权长尾和串行依赖。用实际可持续速率校准，而非只有芯片标称峰值。

```
T >= max(整数运算/可持续算力,
         HBM事务/可持续HBM带宽,
         L2事务/可持续L2带宽,
         L1与L0搬运/对应吞吐,
         UB与Vector服务时间,
         必需下发和依赖链下界)
```

各阶段重叠程度决定上式能否接近，启动、填充、排空和专家长尾还可能使实际时间更大。对于 Exp/Div，应测具体向量服务率。单 kernel 的完整流程包括预处理、元数据、零填充、同步与最终写回。

| 量 | 应记录的内容 | 常见误读 |
|---|---|---|
| 申请容量 | Host workspace 和片上分配 | 容量减少就等于流量减少 |
| 活跃地址集合 | 当前在途、最后读者前的地址范围 | 总容量相同就缓存行为相同 |
| 逻辑请求字节 | 指令请求、padding、重复读、布局转换 | GM 请求全部等于 HBM 事务 |
| 真实层次事务 | PMU 命中、事务数、层次带宽 | 一个命中率可直接换算全部物理流量 |

## 从最后消费者倒推表示

对每个“生产→转换→消费”链，检查生产者能否直接给出下游需要的布局、分块或精度。此题禁止在 GELU 前把反量化结果降为 FP16，因此 INT32/FP32 中间值不能只因节省字节就转 half。最终 GELU 完成后直接产出 FP16 ND 则符合消费需求。

布局融合也要量化：省去一个转换 kernel 不代表省去转换工作；为输出整行而长期持有 tile，可能推迟首包并占满 UB。应允许较小的完整行组尽早输出，且验证跨 N 面板的原始行坐标和唯一写入 owner。

## 用事件退休地址，而非等待整轮结束

为每个缓冲记录：

| 字段 | 示例 |
|---|---|
| 地址/容量 | B1 的两个互不重叠 K256 宽面板 |
| 生产者 | MTE2 |
| ready | 搬入完成后 MTE2→MTE1 |
| 消费者 | 一个或多个 LoadData / MMAD 阶段 |
| 最后读者 | 最后一个实际 MTE1 读该面板的动作 |
| reuse credit | MTE1→MTE2，允许下一专家覆盖 |
| 代数责任 | 完整 true-K 只归并一次，不丢、不重 |

ready 只允许开始读，不允许覆盖。消费函数返回也不一定代表异步读完成。跨代 event 要验证初始 token、每代产生/消费次数、尾块与空专家退出路径。保留有限事件模型和上板数值边界检查，但不要把它们称为全程序证明。

## 联合设计供给、计算、消费

先确定最长完成链，再同时选择 A/B 在 L1 的驻留范围、N 面板供给宽度、L0C 在途平面数、FIX 发出时机、C 地址环、AIV 半块大小、scale 复用和最终写出粒度。

目标是让当前消费者充分有数可用，并使未来生产不阻塞当前消费。若当前 q0/q1 都已 ready，应审查是否被未来 K 的 wait 挡住；若较早 C 已被最后读者搬离，可退休 GM 槽而不等 GELU/最终写出全部完成。与此同时要保留对 UB 仍被 Vector/MTE3 使用的独立保护。

不能把“更宽、更多缓冲、更多并发”作为目标。它们可能挤掉 A 驻留、增加 B padding、稀释核数、推迟小块 ready 或使输出成为新尾部。用完整 Task 和对应关键组的 PMU 检查。

## 分布覆盖与接受标准

建议固定：均分、一个大专家、所有行集中首/尾专家、含连续空专家、随机长尾、边界 tile、非对齐 K/N；数值覆盖全 INT8、抵消、GELU 中间区和饱和区。测试输入仅用于验证泛化，不根据样本分布跳过必要计算。

记录控制组和候选的源码 SHA、构建/ELF 身份、Host 路线、warmup/target、配对顺序、每组统计、频率与设备。PMU 与普通计时分别保存。平台结果附 SID 和评分时期；隐藏整体分数只能提供有限归因。

晋升索引应说明收益在哪个输入族成立、是否平台验证、已知退化和回退方案。请求减少但本地持平的候选可进入平台检验队列，不能直接宣布成功。负结果同样保留机制和代价证据。
