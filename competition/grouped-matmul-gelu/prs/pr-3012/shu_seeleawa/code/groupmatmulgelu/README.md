## 算子实现介绍

本实现基于 AscendC 完成变长分组矩阵乘、逐通道反量化和 GELU 的融合计算。输入与权重采用 INT8，矩阵乘采用 INT32 累加；根据实际 group_list 确定各专家的行区间，支持非均匀分组和空专家，最终输出连续 FP16 张量，保持输入行的排列顺序。

Host 侧负责形状检查、资源查询、分块规划和工作区分配，根据矩阵规模、地址对齐及片上存储容量选择计算入口，不读取输入数值参与算子计算。每次调用只启动一个计算 Kernel，权重打包、矩阵乘、反量化、激活及输出写回均在该 Kernel 内完成。

Device 侧采用 Cube 与 Vector 协同执行。Cube 负责分块矩阵乘，通过 L1 驻留、权重复用和多缓冲流水重叠数据搬运与计算；Vector 负责逐通道缩放、GELU 和 FP16 输出转换。两侧通过跨核事件协调中间结果的生产与消费，循环复用工作区，避免覆盖尚未读取的数据。对于不对齐维度，在 Device 内完成必要的补零和布局转换，输出仅写入有效区域。

针对不同规模，代码保留标量、小矩阵、短组、长 K、窄列和宽列等计算路径。任务划分依据实际专家边界生成，不假设各组均分。非均匀分组的分波路径进一步根据工作量和非空专家数量选择切分点及执行顺序，使后一波权重准备与前一波矩阵乘重叠；后处理使用 FP32 FMA 合并部分 GELU 多项式运算，减少指令和同步开销。

数值实现上，部分紧凑行分支采用缩放后的 FP16 累加结果暂存，再恢复为 FP32 完成反量化和激活；小型标量入口保留分段近似。这些属于当前实现的数值与带宽折中，不能将全部路径描述为完整的 FP32 中间链路。
