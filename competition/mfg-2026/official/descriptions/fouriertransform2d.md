## 算子说明

### 算子功能

科学计算、信号处理与频域仿真（如光波/声波传播、谱方法求解 PDE）中，二维离散傅里叶变换（2D DFT）是最核心的频域算子。该赛题要求在 NPU 上实现单算子形态的二维 C2C（复数到复数）FFT。

`FourierTransform2D` 对形状为 `(B, N, M)` 的复数张量逐 batch 执行二维离散傅里叶变换；当属性 `inverse=True` 时执行逆变换，且逆变换包含 `1/(N·M)` 归一化因子，语义与 CPU `torch.fft.fft2` / `torch.fft.ifft2` 逐点一致。

计算规则：

```
正变换:  y[b,k,l] = sum_{n=0..N-1} sum_{m=0..M-1} x[b,n,m] * exp(-2πi(kn/N + lm/M))
逆变换:  x[b,n,m] = (1/(N·M)) * sum_{k,l} y[b,k,l] * exp(+2πi(kn/N + lm/M))
```

### 输入输出规格

| 张量 | 形状 | 数据类型 | 含义 |
|------|------|---------|------|
| x | [B, N, M] | complex64 | 输入复数张量 |
| y | [B, N, M] | complex64 | 输出复数张量，与 x 同 dtype |

维度约束：B ∈ [1, 256]，N, M ∈ [2, 8192] 且均为 2 的幂。输入分量取值有限，不支持 NaN、+Inf、-Inf，取值在 [-1, 1]。

### 属性参数

| 参数 | 类型 | 默认值 | 含义 |
|------|------|--------|------|
| inverse | bool | False | True 表示逆变换（含 1/(N·M) 归一化） |

### 功能示例

能量守恒（Parseval）：x 为 [1, 8, 8] complex64，分量在 [-1,1] 均匀随机。`y = fft2(x)` 后 `sum(|y|^2) = N·M · sum(|x|^2) = 64 · sum(|x|^2)`；再执行 `inverse=True` 得到的结果与 x 逐点一致（误差在 float32 舍入内）。

### 任务要求

针对不同 B、N、M（含 2 的幂直到 8192），设计算子逻辑，保证复数精度正确（结果满足 atol = 1e-3、rtol = 1e-3）。

充分发挥 NPU 带宽与多核并行能力：行/列变换分阶段复用数据于片上存储，减少 Global Memory 往返；针对 2 的幂长度使用迭代基-4/基-8 蝶形与位反转优化；batch 维并行划分。

**禁止事项**：禁止调用覆盖完整语义的现成 FFT 库接口，禁止回退到 CPU，禁止改变归一化约定（逆变换必须含 1/(N·M)）。
