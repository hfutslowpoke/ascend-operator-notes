## 算子说明

### 算子功能

稀疏图结构乘：多跳邻接矩阵 A²（two-hop 邻居展开）、异质图元路径连接（如 user-item-user）都依赖稀疏×稀疏乘法，是图预处理与采样管线的重载算子。COO 稀疏 A(M, K) 与 B(K, N) 相乘得 C(M, N)，输出为 A、B 按 k 匹配的模式交集。本算子对应 torch_sparse.spspmm。

计算规则：

```
C[i, n] = sum_k A[i, k] * B[k, n]（仅对 A、B 按 k 匹配的模式交集位置）
indexC = 模式交集位置的 COO 索引，行主序（行升序、行内列升序）
valueC = 对应累加值；同一 (i, n) 的多个 k 贡献求和
累加和恰为 0 的坐标保留（按模式不按数值剪枝，与 torch_sparse 一致）
输出为定槽位：indexC (2, m·n)、valueC (m·n)，槽位按行主序排列真实条目
E3 = |模式交集| 为数据相关（恒有 E3 ≤ m·n）：前 E3 个槽位为真实条目，
其余槽位填充 indexC = (-1, -1)、valueC = 0；无交集时 E3 = 0（全部槽位为填充值）
```

### 输入输出规格

| 张量 | 形状 | 数据类型 | 含义 |
|------|------|---------|------|
| indexA | (2, E1) | int64 | A 的 COO 行列索引 |
| valueA | (E1) | float32/float16 | A 的非零值 |
| indexB | (2, E2) | int64 | B 的 COO 行列索引 |
| valueB | (E2) | float32/float16 | B 的非零值 |
| indexC | (2, U) | int64 | C 的 COO 索引槽位，U = m·n，行主序；前 E3 个为真实条目，其余 = (-1, -1) |
| valueC | (U) | 与 valueA 相同 | 前 E3 个为交集位置值，其余 = 0 |

维度约束：M, N, K ∈ [1, 10000000]，E1, E2 ∈ [1, 5000000]，输出槽位 U = m·n（数据无关，U ≤ 250000 保证内存可控）；E3 ∈ [0, U] 为数据相关（A、B 按 k 匹配无任何 (i, n) 配对时 E3 = 0，全部槽位为填充值）。输入 COO 必须行主序（行升序、行内列升序）且无重复条目（coalesced）；valueA 与 valueB 必须为相同 dtype，valueC 跟随该 dtype；float32 精度 atol = rtol = 1e-4，float16 精度 atol = rtol = 1e-2；indexC 逐位一致（atol = rtol = 0）。注：维度属性 (m, k, n) 为每用例显式给出的维度参数（声明带默认值 64，与 torch_sparse.spspmm 的维度参数对齐）；维度可能大于 index 上限（如全零尾行/空列），不可由输入推断；缺省时按默认值 (64, 64, 64) 处理。

### 属性参数

| 参数 | 类型 | 默认值 | 含义 |
|------|------|--------|------|
| m | int | 64 | A 的行数（M），每用例显式给出 |
| k | int | 64 | A 的列数 = B 的行数（K），每用例显式给出 |
| n | int | 64 | B 的列数（N），每用例显式给出 |

### 输入数据约束（结构化张量生成要求）

CSR 类输入（indptr/rowptr/ptr_*）必须单调不减且末位等于对应张量长度；索引类输入（index/col/COO）必须落在合法区间；COO 输入需按行主序排列且无重复条目。随机图测试数据为幂律度分布（含 hub 节点与孤立点）。

### 语义核对说明

本算子语义已对照参考库源码核对：pyg-lib（`pyg_lib/csrc/`）与 torch_scatter / torch_sparse（`projects/pytorch_scatter`、`projects/sparse1/pytorch_sparse`）。规格以赛题规格表为准，与参考库实现的一致性及差异点已在维度约束与计算规则中注明。

### 参考实现说明

参考实现以 numpy 编写（`spspmm.py` 的 `impl` 函数），float32 / float16 原生支持；bfloat16 用例由测试框架以 float32 golden 做精度转换后比对。索引类输出（int64）要求与 golden 逐位一致。

### 功能示例

indexA = [[0,0,1],[0,1,1]]，valueA = [1,2,3]；indexB = [[0,1],[1,0]]，valueB = [4,5]（即 A=[[1,2],[0,3]]，B=[[0,4],[5,0]]），attrs = {m: 2, k: 2, n: 2}

输出：

```
indexC =
[[ 0  0  1 -1]
 [ 0  1  0 -1]]
valueC =
[10.  4. 15.  0.]
```

### 任务要求

针对不同 shape 维度，设计算子逻辑，保证算子精度正确（结果满足测试用例中规定的 atol / rtol；索引类输出需逐位一致）。

充分发挥系统带宽能力和并行计算能力，算子性能更优。本组最难的算子：输出条目 E3 由 A、B 按 k 的模式交集决定，需两段式（先按 k 匹配计数/去重，再填充）或 hash 交集；并发写同一 (i, n) 需要原子归约或排序归并去重；输出槽位固定（m·n），无变长内存规划，未命中槽位可按槽位并行填充；A 按 k 排序或 B 按 k 建 hash 的选择是主要优化点。

**禁止事项**：禁止回退到 CPU；禁止输出未按行主序排序的 indexC；禁止丢弃或合并不同 (i, n) 的坐标（含累加和为 0 的位置）；禁止假设 E3 可先验推断；禁止未命中槽位填充 (-1, -1)/0 以外的值。
