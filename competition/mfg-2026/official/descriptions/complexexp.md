## 算子说明

### 算子功能

复指数是频域分析的基本算子：信号相位旋转、传递函数生成、矩阵指数谱分解等都依赖 `e^(a+b·i)`。

`ComplexExp` 算子逐点计算 `e^(a + b·i) = e^a·(cos b + i·sin b)`，语义与 CPU `torch.exp` 一致。

计算规则：

```
复数: x = a + b·i  ->  out = e^a·cos(b) + i·e^a·sin(b)    (dtype 不变)
实数: x = a        ->  out = e^a                          (dtype 不变)
```

### 输入输出规格

| 张量 | 形状 | 数据类型 | 含义 |
|------|------|---------|------|
| x | [N, M] | float16 / float32 / complex64 | 输入指数 |
| out | [N, M] | 与 x 相同 | 逐点指数 |

维度约束：N, M ∈ [1, 65536]。输入分量取值有限，实部、虚部均在 [-10, 10]，不支持 NaN、+Inf、-Inf。

### 属性参数

无。

### 功能示例

虚数单位：x = 0 + 3.1415927·i（complex64）时，输出约为 -1 + 0·i。

纯虚输入：x = 0 + 1.5707963·i（complex64）时，输出约为 0 + 1·i。

实数路径：x 为 float32 的 2.5 时输出约 12.182494；x 为 0 时输出 1。

### 任务要求

针对不同 shape 与 dtype，设计算子逻辑，保证精度正确：float32 / complex64 配置满足 atol = 1e-4、rtol = 1e-4，float16 配置满足 atol = 1e-3、rtol = 1e-3。

充分发挥 NPU 带宽能力（逐点算子），向量化处理、多核均分元素。
